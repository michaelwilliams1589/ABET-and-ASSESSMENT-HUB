# Version 5.0 Deployment Checklist

1. Extract the ZIP.
2. Replace all files in the GitHub repository root.
3. Commit and push to `main`.
4. Wait for GitHub Pages deployment.
5. Refresh with Ctrl+F5.
6. Sign in.
7. Open System Health and verify Version 5 Stable Core collections.
8. Download a workspace backup.
9. Upload the Canvas gradebook that previously failed.
10. Confirm the assignment review table appears.
11. Save one test assignment.
12. Verify it appears in Assessment Analytics.

# OSUIT ETDE Assessment & Accreditation Hub

## Version 5.1 — Guided Gradebook

This release fixes `Cannot access 'safeRows' before initialization`.

### Gradebook workflow

1. Choose Canvas Gradebook.
2. Choose the class/course first.
3. The Hub displays the official ABET SLO and assignment to look for.
4. The recommended SLO is marked with a star and selected automatically when only one applies.
5. Upload the Canvas CSV or Excel gradebook.
6. Review the official assignment match.
7. Confirm or change the SLO.
8. Save the upload.

Administrators can change the official assignment on the ABET Assignment Mapping page.
